# ⚡ Quick Reference - Top 20 Shortcuts

## Essential (Learn These First)

```
SUBMISSION
├─ ctrl+enter      Submit message
├─ shift+enter     New line (don't submit)
└─ escape          Cancel

MODEL & THINKING
├─ meta+p          Open model picker (Mac: cmd+p)
├─ ctrl+shift+m    Open model picker (Windows/Linux)
├─ meta+t          Toggle thinking (Mac: cmd+t)
└─ ctrl+shift+t    Toggle thinking (Windows/Linux)

NAVIGATION
├─ up              Previous message
├─ down            Next message
├─ ctrl+shift+r    Search history
└─ ctrl+shift+p    Quick open

TOOLS
├─ ctrl+z          Undo message
├─ tab / ctrl+e    Open external editor
├─ ctrl+shift+s    Stash message
└─ ctrl+v          Paste image

GLOBAL
├─ ctrl+k ctrl+t   Toggle todos
├─ ctrl+k ctrl+o   Toggle transcript
└─ ctrl+k ctrl+b   Toggle brief
```

## Keyboard Pattern (ctrl+k chord)

**These use the "ctrl+k" command chord pattern** (press ctrl+k, release, then press the next key):

```
ctrl+k ctrl+t    Todos
ctrl+k ctrl+o    Output/Transcript
ctrl+k ctrl+b    Brief
ctrl+k ctrl+p    Peer/Preview
ctrl+k ctrl+m    Modal/Terminal
```

**Mnemonic**: Think "Control K = Command" then press the letter for what you want

## Common Workflows

### Start a conversation
1. Type your message
2. Press `ctrl+enter` to submit
3. Press `shift+enter` if you need a new line first

### Switch models mid-conversation
1. Press `meta+p` (Mac) or `ctrl+shift+m` (Windows)
2. Use arrow keys to select
3. Press Enter to confirm

### Look up previous message
1. Press `up` to go back one message
2. Keep pressing `up` to go back further
3. Press `down` to go forward
4. Or press `ctrl+shift+r` to search history

### Undo last message
1. Press `ctrl+z` to undo
2. Keep pressing to undo multiple messages

### Take a break / Stash work
1. Type your incomplete message
2. Press `ctrl+shift+s` to stash
3. Come back later and it's still there

### Edit in VS Code
1. Press `tab` or `ctrl+e` to open external editor
2. Make changes in your editor
3. Save and close to return (auto-imports back)

### Add image
1. Press `ctrl+v` to paste from clipboard
2. Or drag/drop image into chat

## Pro Tips

### 🎯 Fastest Submission
Instead of: mouse → find submit button → click
Just use: `ctrl+enter` ✨

### 🎯 Multi-line Messages
Press `shift+enter` to add new line BEFORE hitting `ctrl+enter` to submit

### 🎯 Switch Models Fast
`meta+p` (Mac) or `ctrl+shift+m` (Windows) → Use arrow keys → Enter

### 🎯 External Editor Power
Press `tab` to edit in VS Code when response gets long
*This is game-changing for complex code editing*

### 🎯 History Search
`ctrl+shift+r` then type to find any previous message instantly

### 🎯 Thinking Toggle
`meta+t` or `ctrl+shift+t` before sending to enable/disable thinking

## When to Use Each Shortcut

| Situation | Shortcut | Why |
|-----------|----------|-----|
| Just finished typing | ctrl+enter | Fastest way to submit |
| Need multi-line message | shift+enter | Add lines before submit |
| Want simpler model | left (in model picker) | Less compute, faster |
| Want smarter model | right (in model picker) | More capable |
| Made a typo | ctrl+z | Revert instantly |
| Can't remember what you asked | up | Scroll message history |
| Need to search all history | ctrl+shift+r | Find it fast |
| Response is long/complex | tab | Edit in dedicated editor |
| Done for now, will continue | ctrl+shift+s | Stash your draft |

## Troubleshooting

### Shortcut doesn't work?
- [ ] Are you in the right context? (Chat for submit, Global for toggle todos)
- [ ] Did you release ctrl+k before pressing the next key? (for chord shortcuts)
- [ ] Try restarting Claude Code
- [ ] Check system preferences for conflicting shortcuts

### Want to change a shortcut?
1. Edit `~/.claude/keybindings.json`
2. Find the shortcut you want to change
3. Modify the key or action
4. Save and restart Claude Code
