## Why These 5?

**1. Global Search** (cmd+shift+f)
- Most used Obsidian command
- Finds anything instantly
- Essential for productivity

**2. Toggle Lists** (cmd+shift+l)
- Obsidian's organization tool
- Mapped to todos in Claude (same concept)
- Quick access to task list

**3. Show Outline** (cmd+shift+o)
- Obsidian's outline navigator
- Mapped to transcript (shows conversation structure/context)
- "Zooms out" to see big picture

**4. Link/Command** (cmd+k)
- Obsidian's linking command
- Mapped to history search (finding and linking to previous context)
- Semantic match: finding relevant history to link in conversation

**5. Command Palette** (cmd+shift+c)
- Alternative quick access
- In Claude = global search
- Provides multiple ways to do same thing
