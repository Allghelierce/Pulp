# Pulp Rework Ideas

## Currency: Time
- Single currency: time. 1:1 ratio — minutes focused = time earned
- After growing a tree, user picks: keep the tree OR collect time
- Time is used to buy seeds in the boutique

## Orchard Rework
- One global orchard that resets seasonally
- Seasonal resets enable fresh competition cycles
- Keep per-notebook orchards too — lets users see where their time goes
- Global orchard = competition, notebook orchards = self-reflection

## Competitions (Strava Model)
- Many small competitions anyone can actually win — not one giant leaderboard
- Subset competitions run each season
- Strava-style segments: short bursts, weekly challenges, category-specific races

## Opt-In Tracks
- On first launch, ask user what they want to prioritize:
  - **Consistency** — daily streaks, showing up
  - **Organization** — notebook structure, categorization
  - **Intricacy** — depth of notes, detail
- Separate leaderboards per track
- Prizes for top ~100 in each track

## Goal Commitment System
- User picks a daily goal tier: 15min, 30min, or 90min
- Assigned a boost/multiplier based on chosen tier
- Breaking the commitment = lose all sap (or similar harsh penalty)
- Penalty should sting but not devastate — consider streak multiplier loss or cosmetic badge loss instead of full sap wipe

## Implementation Priority
1. Time currency + keep/collect mechanic
2. Seasonal orchard + one leaderboard
3. Opt-in tracks + segmented competitions
4. Goal commitment system
