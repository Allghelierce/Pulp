## Tips for Maximum Productivity

### Mnemonics
- `ctrl+k ctrl+X`: Think "Control K = Command menu" then press X for action
  - `ctrl+k ctrl+t` = todos
  - `ctrl+k ctrl+o` = transcript (output)
  - `ctrl+k ctrl+b` = brief
  - `ctrl+k ctrl+p` = peer/preview
  - `ctrl+k ctrl+m` = modal/terminal

### Context-Aware Navigation
- **In chats**: Use `up`/`down` for history, or `ctrl+up`/`ctrl+down` for alternatives
- **In diffs**: Use `hjkl` (vim keys) for natural left-right-up-down navigation
- **In lists**: Use `jk` (vim keys) or `ctrl+n/p` for navigation

### Chord Shortcuts
- Chord shortcuts have a 1-second timeout between keys
- Practice hitting `ctrl+k`, releasing, then hitting `ctrl+t` quickly
- These are perfect for commands you use regularly but not constantly

### Customization
- All shortcuts can be modified in `~/.claude/keybindings.json`
- Use the Edit tool to add/remove/change keybindings
- Test with `/doctor` command if available for validation
